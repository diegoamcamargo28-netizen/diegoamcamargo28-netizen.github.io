Proyecto destacado

Folatokfe · Sistema de control financiero y costeo

Aplicación web para un negocio de galletas personalizadas: registra ingresos, gastos, inversiones y compras a crédito, y calcula costos y precios de venta por tamaño y tipo de producto.

JavaServletsMavenTomcatMySQL / MariaDBJDBCREST + JSONJavaScriptHTML / CSS

Qué hace

  • Panel con ingresos, gastos, inversiones, deuda con proveedores y utilidad neta.
  • Registro, eliminación y cambio de estado (pendiente/pagado) de movimientos; filtro por mes y exportación a CSV.
  • Calculadora de costos para galletas de 5, 6, 7 y 8 cm: ingredientes escalados por área, merma, mano de obra, costos variables y costos fijos repartidos por lote.
  • Costos exclusivos y margen propio para tres tipos de producto (didácticas, corporativas y personalizadas), con precio sugerido por tipo y tamaño.
  • Reporte de utilidad por finalidad de la venta.

Decisiones técnicas

  • API REST con Servlets (GET, POST, PUT, DELETE) y respuestas JSON con Gson.
  • Consultas con PreparedStatement y validación en el servidor (tipos, montos con BigDecimal, fechas, longitudes).
  • CORS con lista de orígenes permitidos y credenciales de base de datos por variables de entorno.
  • Frontend sin frameworks: se usa textContent en vez de innerHTML con datos para evitar XSS, y el CSV neutraliza inyección de fórmulas.

Retos que resolví

  • Configurar el despliegue de un WAR en Tomcat con MySQL y diagnosticar errores del driver JDBC y de permisos.
  • Corregir la lógica contable: separar el costo de una compra a crédito del saldo de la deuda.
  • Modelar costos que escalan con el tamaño del producto frente a costos fijos por lote o por mes.

Siguientes pasos

Autenticación de usuarios, edición de movimientos, guardar recetas y lotes en la base de datos y despliegue en la nube.
